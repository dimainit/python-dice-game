# Dice Game

Console dice game written in Python.

## Description

The player competes against the computer by rolling dice.

Points are calculated based on the difference between the dice values.

The game supports:

* Multiple difficulty levels
* Saving results to JSON
* Viewing previous results
* Custom exceptions
* Object-oriented programming

## Project Structure

* main.py - application menu
* game.py - game logic
* models.py - player and computer classes
* settings.py - game constants
* exceptions.py - custom exceptions
* score.py - saving and displaying results

## Features

* Roll dice
* Count score
* Save results to results.json
* View game history

## Technologies

* Python
* JSON
* OOP
* Exception Handling
